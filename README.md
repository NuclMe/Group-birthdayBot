# Birthday Reminder Bot

Telegram-бот на TypeScript: принимает Excel от владельца, объединяет записи с MongoDB и отправляет напоминания в чат.

## Excel

Файл должен содержать заголовки `id`, `name`, `birthday`, `username`.

- `id` — обязательный стабильный уникальный идентификатор;
- `name` — обязательное имя для поздравления;
- `birthday` — `DD.MM`, например `14.03`;
- `username` — необязательный username без символа `@`.

Импорт работает через upsert: новые записи добавляются, существующие по `id` обновляются, отсутствующие не удаляются.

## Локальный запуск через Docker

1. Создайте бота через BotFather и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `OWNER_TELEGRAM_ID`, `TARGET_CHAT_ID`.
3. Запустите:

```bash
docker compose up --build
```

4. Отправьте `.xlsx` боту в личные сообщения.
5. Проверьте `/birthdays`.

`/test_month` и `/test_birthday` позволяют владельцу проверить сообщения сразу, не ожидая расписания.

## Расписание

- 1-го числа месяца в 09:00 отправляется список дней рождения месяца;
- ежедневно в 10:00 отправляются поздравления;
- часовой пояс по умолчанию: `Europe/Kyiv`.

## Команды

`/status`, `/birthdays`, `/reload`, `/test_month`, `/test_birthday` доступны только владельцу.

## Локальный запуск без Docker

```bash
npm install
npm run dev
```

При этом MongoDB должна быть доступна по адресу из `MONGODB_URI`.
